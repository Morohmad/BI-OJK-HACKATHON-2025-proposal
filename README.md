# SATUKAN - Sistem Autentikasi Terpadu untuk Penyaluran Bansos

## Overview

SATUKAN merupakan konsep aplikasi yang diajukan pada **BI-OJK Hackathon 2025** untuk membantu proses verifikasi penerima bantuan sosial (bansos) menggunakan teknologi Face Recognition dan validasi lokasi.

Ide ini dikembangkan untuk mengatasi permasalahan distribusi bansos seperti data ganda, penerima fiktif, dan proses verifikasi manual yang masih rentan terhadap kesalahan maupun penyalahgunaan.

## Konsep Solusi

Sistem melakukan verifikasi penerima bantuan melalui:

* Pengenalan wajah (Face Recognition)
* Validasi lokasi penerima
* Pencatatan hasil verifikasi secara digital
* Dukungan petugas lapangan untuk masyarakat yang tidak memiliki perangkat pribadi

Dengan pendekatan tersebut, proses penyaluran bantuan diharapkan menjadi lebih tepat sasaran, transparan, dan mudah dipantau.

## Teknologi

* Python
* Face Recognition
* TensorFlow
* Geolocation / GPS Validation
* React Native
* Express.js
* Supabase
